# Fiche Ceathar — 54 Open Cards

*A working collection for looking, wondering, recognising, and gathering examples.*

The canonical information is already in place. Everything under **Explorations** is deliberately left open. These pages are not a classification exercise: they are an invitation to spend time with each invariant.

**Reading note:** The **original X–Y traversal** is preserved verbatim from the complete reference table; it is not automatically interchangeable with the triaxial identity. **Ultra-short form** and **companion phrase** are identical in the current canonical sources, so both fields deliberately repeat the same expression.
